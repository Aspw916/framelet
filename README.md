# 帧刻 Framelet

当前版本：1.2.0。新版浅色工作区，统一截图与录制预览，裁剪自动更新；支持 PNG 截图与 GIF 动图。

留住一张画面，或一小段动态。Windows 本地截图与动图工具，中文界面，无账号，无上传，离线运行。

## 直接使用

本仓库提供源码、构建脚本与使用说明，不包含程序二进制、本地录制或测试截图。按下方“源码与构建”生成便携目录后，双击 `release/Framelet/Framelet.exe` 即可运行；打包生成的 ZIP 解压后也可直接使用。

支持 Windows 10/11 x64，使用系统 .NET Framework 4.8 或更高版本；无需安装 Python、Node、FFmpeg 或其他开发环境。FFmpeg 随工具一起提供，`bin` 目录必须与主程序保持在一起。

## 截取静态图片

1. 顶部切换到 **截图**，左侧选择 **全屏 / 窗口 / 局部**。
2. 选择是否显示鼠标、是否延迟 3 秒，然后点击左下方 **开始截图**。
3. 截图直接出现在右侧工作区。点击右下角 **保存 PNG**，或 **复制图片** 后粘贴到聊天、文档或编辑器。
4. 支持 **Ctrl + C** 复制、**Ctrl + S** 保存。顶部切换到“录制”可以继续处理 GIF，切回“截图”仍可看到这张图片。

PNG 按所选范围的原始物理像素保存，保持完整颜色，不缩放、不补偶数边。截图时会自动隐藏主界面和倒计时控制条。保存失败后图片保留，可以换位置重试；截图只在主动保存或复制时输出，关闭工具后不保留未保存的图片。

截图和 GIF 各自保留当前内容，切换任务不会覆盖另一项的预览和裁剪。截图与 GIF 保存目录共用最近一次选择。复制、保存或处理失败会直接在底部反馈，完整信息可悬停查看。

## 录制一个 GIF

1. 顶部切换到 **录制**，选择 **全屏 / 窗口 / 局部**。
2. 全屏模式选择显示器；窗口模式选择一个可见窗口；局部模式点击“框选 / 调整捕获区域”。
3. 框选时拖动创建矩形，拖动内部移动选区，拖动边缘或角点调整大小；方向键微调，Shift + 方向键每次移动 10 像素。按 Enter 或在内部双击确认，Esc / 右键取消。
4. 选择是否显示鼠标、是否倒计时。点击 **开始录制**。
5. 点击录制控制条上的“停止”，或按 **Ctrl + Shift + F8**。最长录制 60 秒，到时自动停止。
6. 自动生成循环预览。拖动裁剪条两端，或填写“开始 / 结束”秒数；停止调整后自动更新，也可点击“更新预览”。
7. 选择画质预设，点击“保存 GIF”，选择保存位置。完成后可点击“打开文件夹”。

改变裁剪时间后，保存 GIF 始终使用最新范围。预览为加快处理最多使用宽 760 px、12 fps，最终导出按所选设置处理。

预览默认适应窗口；顶部“适应 / 100%”按钮或双击画面可切换实际像素。实际大小超出预览区时，可拖动画面查看。预览缩放不会改变保存尺寸。没有捕获内容时，裁剪和导出区隐藏，预览获得更多空间。

**局部录制范围提示**：倒计时期间显示暖黄色边框，录制开始后变为绿色，并在选区外显示“录制中”、时长和像素尺寸。隐藏控制条后边框仍保留，停止或取消时自动消失。选区内部保持可操作，边框及标签不进入录制画面。

## 画质设置

| 预设 | 最大宽度 | 帧率 |
|---|---:|---:|
| 体积小 | 640 px | 10 fps |
| 均衡（默认） | 960 px | 15 fps |
| 清晰 | 1280 px | 20 fps |

也可分别选择宽度和帧率，或使用原始尺寸。保持长宽比例，只缩小不放大。大面积、高帧率和长时间的 GIF 文件更大。

## 捕获范围

- **全屏**：选中的一台显示器，包含桌面与任务栏。
- **窗口**：窗口在屏幕上的完整可见范围，包含边框。录制期间保持窗口可见、位置不变，不要最小化或遮挡。
- **局部**：按物理像素捕获固定矩形。选区可跨显示器；显示器之间没有桌面的部分按系统实际画面记录。
- 本版“整页”指全屏或完整窗口，不自动滚动拼接长网页；录制时手动滚动网页会如实出现在 GIF 中。
- 录制控制条会尝试排除在系统捕获之外。也可以隐藏控制条，用快捷键停止。如果系统或其他应用占用了快捷键，请保留控制条。
- 锁屏、受保护的视频和安全桌面无法保证录入。没有音轨。
- GIF 原始视频为兼容视频编码器，奇数宽高会在右侧 / 底部补至偶数像素，最多增加 1 像素；PNG 截图保持精确尺寸。

## 本地数据与恢复

默认把设置和原始录制写入工具目录下的 `data`。工具目录不可写时，改用 `%LOCALAPPDATA%\Framelet`。

- `settings.json`：偏好、最近保存目录与最近录制位置。
- `sessions/<时间-随机标识>/recording.mkv`：压缩的原始录制。
- `session.json`：时长、尺寸、裁剪范围。
- `preview-*.gif`：预览缓存。
- `error.log`：出错时的本地诊断日志，不包含上传逻辑。

导出失败、取消导出或关闭工具后，源录制保留。再次打开后点击“恢复上次录制”可继续处理。保存采用临时文件和成功后替换的方式，取消编码不会覆盖已有目标。

历史源录制不会自动删除，便于找回；不再需要时，关闭工具后可以删除相应 `data/sessions` 子目录。保存到其他目录的 GIF 不受影响。请按实际需要保留本地录制内容。

## 源码与构建

源码在 `src/`。使用 Windows 自带的 .NET Framework C# 编译器构建；不需要 NuGet。在 Windows 的 PowerShell 7 中，进入仓库根目录运行：

```powershell
.\build.ps1 -FfmpegPath 'C:\path\to\ffmpeg.exe'
.\build.ps1 -Package
```

如果 FFmpeg 已在 PATH 中，可省略 `-FfmpegPath`。使用 FFmpeg 8.x 的 Windows x64 静态构建，需包含 `gdigrab`、`libx264`、`palettegen`、`paletteuse`。发布包仅包含程序、编码组件、说明和许可证，不包含本地录制和设置。

FFmpeg 需由构建者自行提供，构建脚本会复制到本地便携目录；本源码仓库不分发 FFmpeg 二进制。组件来源与许可说明见 [THIRD-PARTY.md](THIRD-PARTY.md)。

复验命令：

```powershell
.\release\Framelet\Framelet.exe --self-test 'C:\absolute\test-output'
.\release\Framelet\Framelet.exe --ui-test 'C:\absolute\ui-output'
```

UI 复验会短暂显示测试窗口并真实录制其动态内容。复验结果和演示输出保存在指定目录，测试数据与日常设置隔离。

需求和决策记录见 [DESIGN.md](DESIGN.md)，本机验收记录见 [VERIFICATION.md](VERIFICATION.md)。复验产生的原片、截图和日志只保存在本地，已通过 `.gitignore` 排除。
